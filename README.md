# Vector Vesper components

WebGL and motion components for React, added to your project as source.

[Website](https://vectorvesper.dev) · [Live previews](https://vectorvesper.dev/components) · [Docs](https://vectorvesper.dev/docs) · [Runtime](https://github.com/vectorvesper/motion-runtime)

</div>

This repo is the public registry for the free components. The `vectorvesper`
CLI reads it when you add one.

Vector Vesper's open-source motion runtime lives in its own repo:
**[vectorvesper/motion-runtime](https://github.com/vectorvesper/motion-runtime)**.

## Quick start

```bash
npx vectorvesper@latest init
npx vectorvesper add physics-buttons
```

The CLI writes the component's source into your project, so it's yours to
change. Every component, with a live preview, is at
[vectorvesper.dev/components](https://vectorvesper.dev/components).

## What's in here

- `components/<slug>/`: the source of each free component.
- `r/`: the built registry the CLI fetches. It's generated, so don't edit it by
  hand.
